# Call-to-action, keyword and post caption

## What the 199 reels do
- 133 (67%) offer something in exchange for a comment keyword. 130 of those use a single word.
- Spoken wording: "comment [keyword]" appears in 120 of the 169 reels with a spoken call-to-action; "I'll send it / DM you" in 97; "follow" in 25; "save or share" in 17; "like" in 9; "link in bio" in 8.
- What the keyword unlocks (multi-label, of 133): a link or repo 89, a guide or setup 37, a skill, file or template 22, a prompt or command 16, a list 14.
- Median comments/views: 1.6% with a keyword offer, 0.1% without. Comments are a funnel metric (people comment to get the link). They do not prove extra reach.

## What stood out in the numbers
| Choice | Result | Strength |
|---|---|---|
| Post caption opens with the call-to-action line | comments/views 1.9% vs 1.0% (72 vs 61 offer reels, p<0.001) | Strong, but correlational |
| Keyword unlocks a guide or setup | 2.0% vs 1.3% (p=0.046) | Weak hint |
| Spoken line includes "down below" | 1.9% vs 1.4% (p=0.09) | Weak hint |
| Spoken line also asks to follow | 1.0% vs 1.7% (p=0.14) | Hint only: one ask per reel is safer |
| "I'll send / DM it" wording | 1.6% vs 1.4% (p=0.22) | No clear effect |

## Rules
1. **One keyword, one ask.** A short, easy-to-type word tied to the topic (CLAUDE, PROMPT, FILE, REPO, GUIDE). Avoid anything that needs capitals, spaces or punctuation.
2. **Make the reward concrete.** "Comment PROMPT and I'll send the exact prompt" beats "comment for more".
3. **Say it three times**: the last spoken sentence, text on screen at the end, and line 1 of the post caption.
4. **Use a unique keyword per reel** so you can tell which reel produced each reply.
5. **Deliver what you promised**, and quickly. The funnel only works if people receive the thing.
6. **Check platform rules** for automated replies and giveaways before running a funnel.
7. **No keyword?** Use one plain ask: "like for more like this" (the 1.83M instant-tip reel did), or a share ask ("send this video to [tool/friend]", used by an 877K reel).

## Spoken call-to-action patterns (write your own wording)
- "If you want [the specific thing], comment [KEYWORD] below and I'll send it to you."
- "Comment [KEYWORD] and I'll send you [the exact prompt / the full setup guide / all five]."
- "Send this video to [tool] and ask it to [fix everything]. Follow for more."

## Post caption
Median 75 words. 140 of 199 end with hashtags. Median 5 hashtags (127 reels use 3 to 5, 49 use none). Hashtag count did not separate winners.

**Template**
```
Line 1: Comment "KEYWORD" to get [specific thing].        <- the call-to-action, first
(blank line)
Line 2: [The hook claim, in plain words.]
Line 3-4: [What it does and the benefit, one sentence each.]
(optional) a short bullet list of the items or features
(optional) a link, if it is a public repo or page
(blank line)
3-5 hashtags
```

**What top captions looked like**
- Curated-list reel: call-to-action line, the hook restated, the stakes ("the right five can replace half your workflow"), then each item described in one line.
- Free-alternative reel: one-line summary, a "Ships with:" bullet list of features, license line, the link, a closing question.
- Stakes reel: the hook restated, then a numbered list of each risk with its number.
The caption repeats the hook's first line in only 21 of 199 reels, so use it to add information, not to copy the spoken line.

## On-screen call-to-action
Show the keyword as large text in the last 2 to 3 seconds (white text on a coloured or dark pill was common). Pair it with a pointing gesture or a screen element that draws the eye.
