# Hook bank

Twelve hook archetypes seen in the 199 reels, with fill-in templates and real examples (handle, views). The examples are short quotes for reference. Write new wording; never reuse a sentence, because identical hooks from smaller accounts landed far below the originals.

**How to use:** pick at least 3 archetypes that fit the topic, write one hook in each, shrink each to 17 words or fewer, then add the on-screen text for second 0 and the first-frame visual. Recommend one.

**Honest caveat:** views mostly follow audience size. The examples show what bigger accounts did, not a guarantee. The 3 to 5 you test on your own account will teach you more than the list.

## 1. The gap
**Template:** "[Thing people use] is great at [A], but it struggles with [B]."
**Examples:** "Claude Code is great at coding, but it usually struggles with front-end design." (@nick_saraev, 1.19M, 45s tutorial)
**Next beat:** introduce the specific fix by name.
**Works when:** B is a pain the viewer already feels. **Watch out:** if B is invented, the payoff never lands.

## 2. Scarcity / curation
**Template:** "[Huge number] of [things], but you only need [small number]."
**Examples:** "Claude is over 100,000 skills, but honestly you only need five of them." (@nick_saraev, 906K). A smaller account used nearly the same line for 142K.
**Next beat:** a numbered list; each item is name, what it does, benefit.

## 3. Gatekeeper warning
**Template:** "Don't [start / use] [X] until you've [Y]."
**Examples:** "Don't start vibe coding with Claude Code unless you've installed these four plugins." (@nick_saraev, 816K). "Don't use Claude Code until you've installed these five plugins." (@buildwithai.club, 615K)
**Why it hooks:** the condition creates a stake and promises a checklist. **Watch out:** list size must match what you deliver.

## 4. Price anchor
**Template:** "[Known paid thing] is $N a month. This is a free version." / "You don't need to pay for [X] anymore."
**Examples:** "Screen Studio is $29 a month, this is a free version." (@marc.kaz, 245K, 28s). "You don't need to pay hundreds of dollars for API keys anymore." (@nick_saraev, 180K)
**Works when:** the paid product is widely known. Show the price on screen. **Watch out:** the free option must really replace it; several reels in the sample were rated low credibility because the claim misstated cost or privacy.

## 5. Rank or underrated claim
**Template:** "This is the #N [category] on [platform] right now and most people haven't heard of it."
**Examples:** "So this right here is the number one open source intelligence tool on GitHub." (@carterperez.dev, 919K). "Ghost Downloader is the #3 GitHub repo right now and most people still haven't heard of it." (@marc.kaz, 469K, 18s). "This is one of the most slept on GitHub repos right now." (@itstundeanthony 280K; the same phrase from another account got 5.6K)
**Needs proof on screen:** rank badge, star count, the repo page.

## 6. Discovery or news
**Template:** "Someone just [built / leaked / open-sourced] [specific thing]." / "You can now [capability]."
**Examples:** "Someone just built the world's biggest prompt library and made it completely free." (@nick_saraev, 240K). "You can now run Claude Code completely free with almost unlimited usage." (@nick_saraev, 491K; another account, 5.1K)
**Freshness matters most:** among reels on the same tool, earlier ones tended to beat later copies. Post early, or add something the others lack (your own demo or result).

## 7. Specific curiosity question
**Template:** "Is there a [named thing] that [surprising result]?" / "Why is everybody suddenly [doing X]?" / "Did you know that in [tool], if you [action], you can [result]?"
**Examples:** "Is there a Claude skill called slash brag that turns any side project into a 20 second launch video?" (@itstundeanthony, 1.23M). "Why the hell is everybody suddenly posting these Jarvis clips?" (@nicholas.puru, 831K). "Did you know that if you come to this GitHub repo here..." (@softwarewithnick, 609K, 23s)
**Rule:** the question must name something concrete. Vague questions do not hook.

## 8. Stakes or fear
**Template:** "Your [thing] can [bad outcome with a number] before [event]."
**Examples:** "Your vibe-coded app can get sued for $100,000 before it makes a single sale." (@adilet.fndr, 877K, 70s). "If you use Claude Code with multiple skills installed, your PC might have got hacked." (@nick_saraev, 166K)
**Rule:** every number must be sourced and shown. This archetype is the easiest to abuse.

## 9. Contrarian or hidden capability
**Template:** "Most people [do X] wrong." / "Most people don't realize you can [capability]."
**Examples:** "Most people using Claude Code completely wrong." (@nick_saraev, 277K). "Most people don't realize you can teach Claude Code almost any skill by teaching it to watch YouTube." (@jens.heitmann, 1.26M; a smaller account, same line, 5.5K)

## 10. Instant utility tip (screen-only, 20 to 25 seconds)
**Template:** "Did you know that in [tool], if you [action], you can [result]?" then show the steps in real time.
**Example:** a Spanish-language VS Code port-forwarding tip, 23 seconds, no face, one trick, ends with a plain "like for more" (@acadeller, 1.83M). The hook sentence contains the entire tip.
**Why include it:** proves a no-face, no-keyword reel can win. Pick one trick, one result.

## 11. First-person proof
**Template:** "This is how I [run / do] [impressive thing]." / "Here's how I save hours by [method]."
**Examples:** "This is how I run my 37+ AI agent team to handle my business." (@bennett.spooner, 238K). "Here's how you can save hours using Claude with Revit and Miro board." (@arch_ai_lab, 221K)
**Needs:** real results on screen. First-person hooks showed a slightly higher likes-per-view rate in the sample (2.6% vs 2.1%), a weak signal.

## 12. Character or skit
**Template:** two characters, one asks the viewer's question, the other answers; or a staged scenario that escalates.
**Examples:** Family Guy characters over game footage walking through a prompt library (@algorithmswithpeter, 771K). A staged "my agents locked me out" terminal skit (@programmergrind, 1.1M, likes/views 6.0%, among the highest in the sample). A raw 3-minute screen rant "This game, it controls my entire existence." (@androo.agi, 2.9M)
**Trade-off:** skits earn high likes per view but few comments (no keyword offer). Do not fake a real product's behaviour; label staged content as a skit.

## Weak patterns (from the bottom of the sample)
"Claude skills that will make your life easier" (2.5K). "Claude needs these 20 connectors" (2.1K). "40 FREE Claude repos that feel illegal" (5.2K). "These are top five websites that changed my life" (4.1K). "This GitHub repo replaces a $50 a month tool!" (1.6K).
Common thread: no specific payoff, no concrete stake, nothing provable in the first frame. These came from small accounts, so audience also explains part of the gap; treat this as a writing heuristic, not a proven cause.

## Translating archetypes outside AI and developer tools
- Price anchor: "[Industry standard software] costs $N a year; here is the free or cheaper route."
- Gatekeeper: "Don't [start the project / send the proposal] until you've [checklist item]."
- Scarcity: "[Huge number] of [options], but you only need [few]."
- Stakes: "[Common mistake] can cost you [number] before [milestone]."
- Instant tip: "Did you know that in [tool you use daily], you can [action] and get [result]?"

## Hook checklist
- 17 words or fewer, ideally 9 to 17.
- One concrete noun and one number or contrast.
- Shown in the first frame; the same claim as text at second 0.
- Not vague, not copied, not a promise the reel cannot prove.
